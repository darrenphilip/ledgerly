Private, offline-first budgeting and spending tracker for Android.

### Install
1. Download `ledgerly-1.3.0.apk` below.
2. Open it on your Android 8.0+ phone and allow installation from unknown sources.

Or: `adb install -r ledgerly-1.3.0.apk`

**Upgrading from 1.2.0:** install straight over the top — same signing key, so your ledger,
budgets and settings are kept. From this version on you don't need this page at all.

### What's new

**Updates arrive in the app**
- Ledgerly now asks GitHub for the latest release when it opens. If a newer version exists,
  Home shows a banner: **Ledgerly 1.3.0 is available → Update**.
- One tap downloads the APK and hands it to Android's installer. No browser, no re-downloading
  from the releases page, no hunting for the file.
- Settings → Updates shows your version, lets you check on demand, and can turn the automatic
  check off. Android will ask once to allow Ledgerly to install apps.
- A failed check is silent — the app never nags and never blocks on the network.

**What this costs, plainly:** the app now holds `INTERNET` and `REQUEST_INSTALL_PACKAGES`.
That is the entire network surface: one request to the release feed, plus the APK download if
you start one. No analytics, no telemetry, no identifiers, and your ledger is never uploaded.
Android only accepts an update signed with the same key as the installed app, so a tampered
download fails to install rather than replacing your data.

### What is included
- Home dashboard with safe-to-spend, budget alerts and a category donut
- Activity list with search, filters and swipe-to-delete with undo
- Monthly and per-category budgets, month-specific overrides, plus the 50:30:20 plan
- Insights: 6-month trend, category breakdown and automatic highlights
- Add/edit sheet with amount pad, emoji categories and date picker
- Recurring entries, backup/restore, CSV export and import
- Light/dark themes, 19 currencies including IDR, app lock
- In-app updates from the public release feed
- No account, no cloud — data stays on device
