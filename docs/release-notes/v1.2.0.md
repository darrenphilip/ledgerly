Private, offline-first budgeting and spending tracker for Android.

### Install
1. Download `ledgerly-1.2.0.apk` below.
2. Open it on your Android 8.0+ phone and allow installation from unknown sources.

Or: `adb install -r ledgerly-1.2.0.apk`

**Upgrading from 1.1.0:** install straight over the top — same signing key, so your ledger,
budgets and settings are kept.

### What's new

**Your data is now recoverable**
- **Back up to a file** in Settings writes one JSON file with every transaction, budget,
  recurring entry and setting. **Restore from a backup** reads it back, either replacing
  what's on the device or merging into it.
- **Import CSV** reads a previously exported file back in. Header, duplicates and unreadable
  rows are handled: you get a count of what was imported, skipped and ignored.
- Schema upgrades no longer resize your data. Ledgerly's database used to drop and recreate
  its tables on any version bump; it now migrates in place, and a test opens a real old
  database to prove the ledger survives.
- Android auto-backup is switched off, so the app no longer copies your ledger to Google
  Drive behind your back. The file you save is the only copy that leaves the app.

**Recurring entries**
- Rent, salary and subscriptions: create an entry with an amount, category, cadence
  (weekly/monthly) and next due date.
- When it comes due, Home shows a card — **Add** logs it and moves the date forward, **Skip**
  moves the date without logging. Months that are missed don't flood the list.

**Budgets per month**
- A category limit can now apply **every month** (the default) or **only to the month you're
  viewing**. October can have a tighter grocery limit without rewriting the rest of the year;
  the Budgets tab marks those rows "This month only".

**Privacy**
- **App lock**: optionally require your device screen lock (PIN, pattern, password or
  biometric) before the ledger opens. The app stores no credential of its own and requests
  no permission for it. Relocks after 15 seconds in the background.

**Smaller things**
- Long-press the launcher icon → **Add expense** opens the amount pad directly.
- Large font sizes (200%) no longer split amounts across lines in the hero card.

### What is included
- Home dashboard with safe-to-spend, budget alerts and a category donut
- Activity list with search, filters and swipe-to-delete with undo
- Monthly and per-category budgets, month-specific overrides, plus the 50:30:20 plan
- Insights: 6-month trend, category breakdown and automatic highlights
- Add/edit sheet with amount pad, emoji categories and date picker
- Recurring entries, backup/restore, CSV export and import
- Light/dark themes, 19 currencies including IDR, app lock
- No account, no cloud, no permissions — data stays on device
